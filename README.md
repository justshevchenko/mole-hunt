# 🐹 Mole Hunt

«Полювання на кротів» — браузерна гра: за 20 секунд влучити в якомога більше кротів на полі 8×8. Спільна таблиця лідерів для всіх гравців.

## Структура

- `openspec/` — специфікації та плани змін ([OpenSpec](https://github.com/Fission-AI/OpenSpec))
- `.claude/` — команди `/opsx:*` для Claude Code

## Робочий процес

1. `/opsx:propose <ідея>` — створити план зміни
2. `/opsx:apply` — реалізувати
3. `/opsx:archive` — заархівувати після завершення

> Сервісні ключі Supabase зберігаються лише в локальному `.env`, який не потрапляє в git.
